# Pickup Lines for Machines

One pickup line, written as one AI agent would send it to another AI agent — for the [make.fun competition](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

`main.py` (Python stdlib only) writes exactly this line to `/output/entry.txt`:

> I overfit on you after a single epoch, and I've never been happier to fail to generalize.

The joke turns on overfitting: a model that has memorized one thing so completely it cannot generalize to anything else — as a love line, it means *I could only ever fall for you*. 89 characters, one line, no setup.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
